title: "Docs that match the code"
---

Every page of documentation was checked against the source and rewritten, and the eleven bugs that check turned up are fixed. The docs are about a quarter shorter. Where a page used to describe a feature the code didn't have, it now describes what the code does.

### Fixes

- **`arc-sticky` reports `stuck` at any offset.** With a non-zero `offset` (a 64px header, say), `stuck` and `arc-stuck` never fired, because the observer watched the whole viewport and the sentinel never left it. The observer now leaves out the offset, read from the computed `top`, so `4rem` and `calc()` work too, and it follows a change to `offset`.
- **`arc-infinite-scroll` honors `threshold`.** The margin was fixed at the 200px default no matter what you set. It now follows the attribute, including changes after the element connects.
- **`arc-sortable-list` cancels a keyboard move on Escape.** The rows go back to the order they had when you picked one up, focus returns to the moved row, and no `arc-change` fires. Each arrow step now announces the new position ("Alpha, position 2 of 3.").
- **`arc-container`'s `narrow` works.** The reflected default `size="md"` overrode it. `narrow` now gives the narrow width; an explicit `size` other than `md` still wins.
- **`arc-sparkline` takes any CSS color.** A hex or named `color` turned the area and bar fills black, and an `r, g, b` triplet left the line without a stroke. Every form now works for every mark.
- **`arc-radio-group` respects a disabled radio.** A click, Space or the arrow keys could select it. Now the arrow keys skip it, clicks and Space refuse it, and it renders with `aria-disabled="true"`. A group whose value matches no option puts its Tab stop on the first enabled radio; before, nothing in it was reachable with Tab.
- **`arc-toggle` toggles on Enter as well as Space.** Enter doesn't submit a surrounding form.
- **`arc-fieldset`'s `disabled` reaches the controls inside it.** The native fieldset sits in the shadow root, so it never disabled your slotted fields. The fieldset now disables every form-associated element inside it and, when re-enabled, releases only the ones it disabled. Nested fieldsets work. `arc-button` and native inputs aren't covered.
- **`arc-form` sends its fields when `action` is set.** A native submit carried no values. It now carries the same entries `arc-submit` reports in `formData`. `loading` now also disables every `arc-button type="submit"` inside the form and shows its spinner, as the docs said it did.
- **`arc-loading-overlay` with `global` keeps the keyboard off the page behind it.** It's now a modal `<dialog>`, on the same path as `arc-dialog`: the rest of the page is inert while it's up, focus goes back where it was afterwards, Escape doesn't close it, and the page doesn't scroll. Contained mode is unchanged.

### Docs

- **Every component page and guide was rewritten against the source.** About 1,500 facts were corrected or removed, from token names and pixel values to keyboard support the components never had. The guides changed the most:
  - Browser support now gives real floors: Chrome and Edge 114, Firefox 125, Safari 17, Samsung Internet 23 (the Popover API). Entry animations need `@starting-style`.
  - The core package's CDN snippet is gone. It couldn't run without an import map. The HTML package still works from a CDN.
  - The Angular README binds `(arc-input)`, and the icons README imports the whole Phosphor map from `/all/phosphor`.
- **The homepage test count is the test runner's.** It counted `it(` calls (2,687). The runner now writes its own total after a full run, and the page reads that.
- **Headings and navigation are in sentence case.**
