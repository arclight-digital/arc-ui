A docs fix for `arc-top-bar`, from getpulsar.dev.

### Docs

- **Hiding the top bar's actions: hide `::part(actions)` as well.** When a site's CSS hides everything in the actions slot (a phone layout that moves them into the menu), the bar closes the gap the empty box leaves. It can only tell the box is empty once it has hydrated, so the server render, and every reader without JavaScript, kept the gap, and the center slot sat 16px to the left of where it lands after load. Hiding `::part(actions)` in the same rule removes the box itself, so there is nothing to collapse and the page renders the same with and without script. The part's description and the top-bar guidelines now say so.
