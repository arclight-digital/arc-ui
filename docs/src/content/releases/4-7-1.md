---

Two fixes found by building the new homepage out of ARC itself: the `hidden` attribute now hides every component, and the code block's copy button stops sitting on your code.

### Fixes

- **`hidden` hides, everywhere.** A component's own `:host` display outranked the browser's `[hidden] { display: none }`, so setting `hidden` on an `arc-list-item`, a button, a card or almost anything else left it on screen. One shared rule now covers every component. If you worked around this with your own `[hidden]` rule, it can go.
- **`arc-code-block`'s copy button moves into the header bar.** On every `window` block, and on a default block with a `filename` or `language`, the button sits at the end of the header instead of floating over the code. Long lines no longer scroll under it, and the code gets back the column it reserved. A default block with no header keeps the floating button; `basic` is unchanged.
