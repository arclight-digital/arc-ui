An application built on ARC ranked what it was still drawing by hand by how much code each missing feature would let it delete. This release covers the items that were gaps in existing components. The ones that need new components come later.

### Row Actions On `arc-list-item`

The new **`actions`** slot holds per-row buttons such as rename and delete. They appear when the row is hovered or when anything in it has focus, so a keyboard user can reach them. On a device without hover they are always shown. A click or key press on an action never selects the row, and the arrow keys still move between rows from an action.

```html
<arc-list-item value="weekly">
  Weekly review
  <arc-icon-button slot="actions" name="pencil" label="Rename Weekly review"></arc-icon-button>
</arc-list-item>
```

### A Waveform That Steps

**`steps`** turns `arc-waveform` into a scrubber over discrete frames, such as a replay. Arrow keys move one step, Page Up and Page Down a tenth of the track, and pointer scrubbing snaps to steps. The slider reports step numbers rather than a percentage. **`value-text`** replaces what it announces ("85 of 200 ms"). Set it in your `arc-input` handler and it arrives with the new position.

### Meters And Gauges That Aren't About Status

`arc-meter` and `arc-gauge` take a **`mode`**:

- **`zones`**, the default and unchanged, colours by the low/high/optimum thresholds.
- **`plain`** draws in one colour (`--meter-fill`, `--gauge-fill`), for a quantity that is neither good nor bad. A usage count isn't a warning.
- **`diverging`** fills from **`center`** toward the value, with each side in its own colour (`--meter-below` / `--meter-above`, and the same for the gauge). It suits a lean in either direction, from −1 to +1. The value is shown and announced with its sign, and a tick marks the centre.

```html
<arc-meter label="Lean" mode="diverging" min="-1" max="1" value="0.4"></arc-meter>
```

The diverging defaults are chart series 1 and 2, a pair already validated to stay distinguishable under colour-vision deficiency.

### A Stat For A Dense Layout

`arc-stat` takes **`size`** (`sm`, `md` or `lg`, with `md` unchanged) and **`plain`**, which drops the gradient, glow and rule. A strip of vitals beside other content can now use it without it shouting.

### `arc-empty-state` Is Quiet By Default

**This is a behaviour change.** Every `arc-empty-state` used to be a live region (`role="status"`), so screen readers announced it on appearance and read out anything that changed inside it: a countdown was read on every tick. An empty list on page load is not news, so the role is now opt-in with **`announce`**:

```html
<arc-empty-state heading="No results" announce></arc-empty-state>
```

If your page relied on the announcement, typically a "no results" state after a search the user just ran, add `announce`.
