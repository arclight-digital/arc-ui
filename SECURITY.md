# Security policy

## Reporting a vulnerability

If you find a security vulnerability in ARC UI, report it privately.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email **hello@arclight.build** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

We acknowledge reports within 48 hours and aim to ship a fix or mitigation for critical issues within 7 days.

## Scope

This policy applies to the ARC UI packages published under `@arclux/` on npm:

- `@arclux/arc-ui` (web components)
- `@arclux/arc-ui-react`
- `@arclux/arc-ui-vue`
- `@arclux/arc-ui-svelte`
- `@arclux/arc-ui-angular`
- `@arclux/arc-ui-solid`
- `@arclux/arc-ui-preact`
- `@arclux/arc-ui-html`
- `@arclux/arc-ui-icons`

## Supported versions

4.x gets security fixes. 3.x gets them until 2026-11-16, a quarter after the v4.0.0 tag. After that, only the latest release does.
