# Security policy

## Reporting a vulnerability

If you find a security vulnerability in ARC UI, report it privately.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email **hello@arclight.build** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
